The date range is a two-handle slider over the 437 Saturdays on file (dashboard.all_weeks -- one shared list, since every chart publishes weekly on Saturdays). A browser has no built-in two-handle slider, so it's the standard trick: two ordinary range inputs stacked on one track, each owning one handle.
